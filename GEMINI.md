# Project Guidelines

## Core Principles
1. **NO MOCK DATA**: Xech qanday mock data ishlatilmaydi. Barcha ma'lumotlar to'g'ridan-to'g'ri backend API va ma'lumotlar bazasi (PostgreSQL/SQLite) bilan ishlashi shart.
2. **Direct Integration**: Frontend va Backend o'rtasida faqat real HTTP API (REST/JSON) va real ma'lumotlar saqlanishi kerak.
